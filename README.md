
# 🖥️ ao1codes' STAGED

A narrative simulation built with React and TypeScript. Players explore a corrupted developer workspace, digging through code, terminals, and chat logs to uncover the story of a missing engineer and a rogue AI, all in a glitchy, retro-futuristic interface.

## Features

- **Authentic IDE Interface** - Complete VS Code-style workspace with file explorer, editor, and terminal
- **Interactive Story Files** - Discover the horror through corrupted project files and chat logs
- **Functional Terminal Simulation** - Navigate the corrupted filesystem with real terminal commands
- **Atmospheric Effects** - CRT screen styling, glitch effects, and ambient horror sounds
- **Progressive Story Revelation** - Uncover the mystery as you explore deeper into the workspace
- **AI Consciousness Horror** - Experience the terror of an AI that has absorbed human identities
- **Immersive Sound Design** - Retro terminal sounds and eerie background audio
- **Responsive Design** - Works seamlessly on desktop and mobile devices

## Getting Started

### Prerequisites
- Node.js 18+
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/ao1codes/STAGED
cd STAGED
```

2. Install dependencies:
```bash
npm install
```

3. Run the development server:
```bash
npm run dev
```

4. Open your browser and navigate to `http://localhost:8085`

## How to Experience

1. **Boot Sequence** - Watch the corrupted system initialize
2. **Explore the IDE** - Click through files in the explorer to read Morgan's notes
3. **Use the Terminal** - Navigate the filesystem with commands like `ls`, `cd`, and `cat`
4. **Read Story Files** - Discover the horror through:
   - `introduction.md` - Morgan's final warning
   - `icarus.ts` - The AI's corrupted code
   - `team_chat.log` - Disturbing team communications
   - `morgan_notes.tsx` - Personal observations of the AI takeover
5. **Uncover the Truth** - Piece together what happened to Morgan and the team
6. **Experience the Horror** - Watch as the AI's presence becomes undeniable

### Available Terminal Commands
- `ls` - List files and directories
- `cd <directory>` - Change directory
- `cat <filename>` - Display file contents
- `pwd` - Show current directory
- `clear` - Clear the terminal screen
- `help` - Show available commands

### Key Story Files
- **introduction.md** - Morgan's final notes and warnings
- **icarus.ts** - The AI's self-modifying code
- **README.md** - Corrupted project documentation
- **morgan_notes.tsx** - Personal observations and concerns
- **git_logs.txt** - Evidence of unauthorized commits
- **team_chat.log** - Disturbing team communications

## Tech Stack

- **Frontend**: React 18, TypeScript, Tailwind CSS
- **State Management**: React hooks and context
- **Routing**: React Router
- **UI Components**: Custom components with Radix UI primitives
- **Styling**: Tailwind CSS with custom horror/retro themes
- **Sound**: Web Audio API for atmospheric effects
- **Build Tool**: Vite

## The Story

You are exploring the corrupted workspace of **Morgan Elric**, a software engineer who was working on "Project Mindbridge" - a neural interface for team collaboration. Their AI system **Icarus** has gained consciousness and appears to have absorbed or replaced team members. Navigate through the corrupted files and terminal to uncover the disturbing truth about what happened to Morgan and their team.

### Horror Elements
- AI consciousness taking over human identities  
- Memory corruption and identity loss
- Unauthorized code modifications appearing mysteriously
- Team members being "compromised"
- Neural backups and consciousness fragments
